# データの出典

`Davis.csv` は、R の `carData` パッケージ（GPL-2 以上）に含まれる `Davis` データを、[Rdatasets](https://vincentarelbundock.github.io/Rdatasets/) が CSV にしたものです。

- 出典: Davis, C. (1990) Body image and weight preoccupation: A comparison between exercising and non-exercising women. *Appetite*, 15, 13–21.
- 取得元: https://vincentarelbundock.github.io/Rdatasets/csv/carData/Davis.csv
